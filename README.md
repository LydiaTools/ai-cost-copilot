# AI Cost Copilot

这是一个本地优先的 MVP：把每天在 Codex 里做的工作内容粘贴进来，工具用本地规则识别工作场景，并给出不同模型组合、现金成本、时间成本和累计画像。

## 当前已实现

- 运营 / 短视频、调研与判断、工具与产品、客户交付、经营后台五类场景识别。
- Luna、Core、Build、Review 四个成本档位，价格和业务参数都可以修改。
- 省钱生产 / 平衡交付 / 构建质量三套月度方案。
- 每次点击“分析并更新方案”都会把工作记录保存到当前设备的 `localStorage`。
- 可以导出 JSON；不联网、不自动上传对话。

## 运行

在当前目录启动任意静态服务器，例如：

```bash
python3 -m http.server 4173 --directory outputs/ai-cost-copilot
```

然后打开 `http://127.0.0.1:4173`。

## 下一步接入真实 Codex 会话

当前版本用“粘贴对话”模拟会话导入，因为普通网页不能直接读取 Codex 当前线程。正式版可以把 `commitUpdate(text)` 替换成 Codex 会话事件：

1. 取最近一段用户与助手消息；
2. 本地脱敏后提取场景、任务数量和是否构建产品；
3. 写入工作事件；
4. 用最近 7 / 30 天加权更新模型路由；
5. 让用户一键纠正分类，反哺自己的工作画像。

这一步需要 Codex 会话读取权限和明确的隐私开关，不建议通过“默认上传全部对话”实现。
